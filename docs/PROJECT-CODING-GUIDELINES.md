# JobPilot - Project Instructions

## Project Overview
JobPilot is a Java Spring Boot application
designed to help users manage job applications
and generate tailored resumes.

## Technology Stack
- Java
- Spring Boot
- Maven
- Spring Data JPA
- HTML, CSS, JavaScript

## Project Architecture

### entity
Contains database entities.

### model
Contains application models and DTOs.

### repo
Contains Spring Data repositories.

### service
Contains business logic.

### web
Contains REST controllers and web configuration.

## Coding Guidelines
- Follow Java naming conventions.
- Keep business logic inside service classes.
- Keep controllers lightweight.
- Use constructor-based dependency injection.
- Follow REST API conventions.
- Handle exceptions properly.
- Avoid hardcoding API keys and credentials.

## Before Modifying Code
- Understand existing implementations.
- Check dependencies before adding new ones.
- Avoid breaking existing functionality.
- Explain significant architectural changes.
